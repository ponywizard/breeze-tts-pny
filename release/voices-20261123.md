Queen Chrysalis joins the Breeze roster with a 5.14-second reference from *The Mean 6* (S08E13), “The castle search.” The pack includes 140 voices and six Mane Six adapters. You can use her in Companion on its own or install the [Queen Chrysalis character mod](https://mods.pones.top/mod/69) to meet her in Home: Equestria.

## Update Companion 0.3.3

1. Stop Companion. Download **`breeze-pny-curated-voices-20261123.tar.gz`** from the assets below. Keep it compressed and place it in the extracted Companion 0.3.3 package folder.
2. Open a terminal in that folder and run the command for your platform. If you originally used a custom installation prefix, add `--prefix` with that same directory.
3. Once setup finishes, restart Companion, open **Generate**, and search for **Queen Chrysalis**. API clients can use `character_id` = `chrysalis` or legacy `speaker_id` = `7`.

**Windows (PowerShell)**

```powershell
.\setup.cmd --update --voice-pack breeze-pny-curated-voices-20261123.tar.gz --voice-pack-sha256 a28026d68fce5f77478aa2b169bae19837a3c89dd65e6ac41f764f2e92505d89
```

**Linux**

```bash
python3 installer/install.py --update --voice-pack breeze-pny-curated-voices-20261123.tar.gz --voice-pack-sha256 a28026d68fce5f77478aa2b169bae19837a3c89dd65e6ac41f764f2e92505d89
```

The update reuses your installed model and carries forward compatible personal voices. If you previously added your own character with ID `chrysalis`, setup will stop on that collision. To adopt the curated voice, keep a copy of your personal WAV and transcript, remove the custom entry under **Voices**, stop Companion, and rerun the update.

**New installation?** Download and extract [Companion 0.3.3 for Windows](https://github.com/ponywizard/breeze-tts-pny/releases/download/v0.3.3/breeze-tts-pny-0.3.3-windows-x86_64.zip) or [Companion 0.3.3 for Linux](https://github.com/ponywizard/breeze-tts-pny/releases/download/v0.3.3/breeze-tts-pny-server-0.3.3-linux-x86_64.tar.gz). Follow the steps above, omitting `--update` on first installation.

Game mod 0.1.3 works with this pack. The Queen Chrysalis character mod uses the same profile ID in disguise, so disguised forms also speak with this voice.

Upgrade checks passed on Linux and with the packaged Windows installer under Wine. Both kept the selected model, settings and existing custom voices. On Linux, the game API generated the same audio for the named and numbered Chrysalis routes.
