# Linux companion installation

The companion runs Breeze-TTS-2, selects each character's reference and adapter, and streams speech to the game mod. The curated pack has 139 reference voices and six Mane Six adapters. One pinned Q8 model and the adapters stay resident; synthesis uses one slot.

For Windows, use [the Windows package](WINDOWS.md), which includes Python and the game mod.

## Requirements

- Linux x86_64, an AVX2-capable CPU and a working Vulkan GPU driver/loader.
- Python 3.11+ and its standard library. Setup installs no pip packages or system services.
- glibc 2.38+ and libstdc++ providing `GLIBCXX_3.4.32`, plus the OpenMP runtime (`libgomp.so.1`). Older Linux baselines require a source build. musl builds are not included.
- At least 6 GB of free space for the companion/model/assets. Setup downloads a pinned model of about 3.6 GB.

## Install

Download these matching release files:

- `breeze-tts-pny-server-0.2.1-linux-x86_64.tar.gz`
- `breeze-pny-curated-voices-20261107.tar.gz`
- `breeze_tts_pny-0.1.1-linux-x86_64.pck` for the game

`SERVER-SHA256SUMS` records the companion/voice archive hashes; `SHA256SUMS` records the game-pack hash. The native runtime is included in the companion archive.

Extract the server archive, put the voice-pack `.tar.gz` inside the extracted folder alongside `installer/`, and leave the voice pack compressed:

```bash
tar -xzf breeze-tts-pny-server-0.2.1-linux-x86_64.tar.gz
cd breeze-tts-pny-server-0.2.1-linux-x86_64
# Copy the downloaded voice archive into this directory before continuing.
breeze_pny_prefix="${XDG_DATA_HOME:-$HOME/.local/share}/breeze-tts-pny"
python3 installer/install.py --prefix "$breeze_pny_prefix"
```

Setup verifies the runtime, imports the voices/adapters, downloads and verifies the model, and prints the exact start command. Transfer progress and checksum verification are shown in the terminal. Use `--prefix /your/path` for another location or `--python /path/to/python3` to choose another Python 3.11+ interpreter. Keep that interpreter available after setup.

For an offline model, add `--model-file /path/to/breeze-tts-2-q8_0.gguf`. The hash must match the pinned model. Verified installed files are reused; a failed download leaves verified assets intact. Downloads restart from the beginning on retry.

The voice archive may also be beside the extracted server folder. Custom locations use `--voice-pack` or `--runtime-bundle`; HTTPS URLs also require their corresponding `--voice-pack-sha256` or `--runtime-sha256`. A release base URL can be supplied with `--release-base-url`.

## Run and connect

Using the installation path from setup:

```bash
breeze_pny_prefix="${XDG_DATA_HOME:-$HOME/.local/share}/breeze-tts-pny"
"$breeze_pny_prefix/bin/breeze-pny" doctor
"$breeze_pny_prefix/bin/breeze-pny" serve
```

Wait for the `ready` event, then leave that terminal open while playing. `doctor` checks files/dependencies and native executable startup; `serve` plus a speech request verifies GPU synthesis. Startup checks the reference caches against the voice pack. Ctrl+C stops the companion and its owned native process.

In the game, open **Settings → Mods → Open mods folder**, copy in the Linux `.pck`, and restart. Select the MOSS-compatible TTS provider, enable TTS/automatic voices, and set its URL to **`http://127.0.0.1:18792/tts`**. Start the companion before loading a world. LLM and optional STT configuration are separate and remain unchanged.

The MOSS label is the game's existing HTTP provider setting; speech is generated by Breeze.

To test speech without the game, open another terminal:

```bash
breeze_pny_prefix="${XDG_DATA_HOME:-$HOME/.local/share}/breeze-tts-pny"
"$breeze_pny_prefix/bin/breeze-pny" smoke --character pinkie_pie --output pinkie-test.wav
"$breeze_pny_prefix/bin/breeze-pny" smoke --character spike --output spike-test.wav
```

Listen to the saved WAV files and check the reported adapter (`pinkie` or `base`). Without `--output`, the check validates the stream and reports timings without saving or playing audio. `voices` lists character IDs.

To browse references or replace one, stop the companion and run the installed launcher with `voice-library`. The [local browser wizard](VOICE_LIBRARY.md) converts audio, generates previews, saves validated personal packs, and supports undo.

## Ports and startup problems

The game-facing router uses port **18792**; the private native renderer uses **18797**. Use the router's `/tts` URL in the game. For other ports:

```bash
breeze_pny_prefix="${XDG_DATA_HOME:-$HOME/.local/share}/breeze-tts-pny"
"$breeze_pny_prefix/bin/breeze-pny" serve --port 19092 --native-port 19097
```

Use the same public port in the game URL. Edit the installation's `config.json` for persistent changes. Asset paths in that file are relative to the installation directory.

An existing companion must be stopped before another starts. The companion does not stop other programs to claim their ports. A recently closed native port can need up to 75 seconds to become available; startup reports that wait. If streaming never enables, check TTS/voice settings, the URL and service readiness, then reload the world to restart capability detection.

For a missing shared library or unsupported CPU/driver, `doctor` reports the native startup error. Install the appropriate system dependency or use a build for your Linux baseline.

## Another machine

Install the companion on that computer and forward its loopback router:

```bash
ssh -N -L 127.0.0.1:18792:127.0.0.1:18792 user@inference-machine
```

Keep this terminal open. The game still uses `http://127.0.0.1:18792/tts`. On a trusted LAN, `serve --host 0.0.0.0` exposes the router for the game to use that machine's LAN IP. The HTTP interface has no authentication or TLS; native synthesis remains on loopback.

## Updates, logs and removal

Stop the companion, extract the new release, keep the voice archive available, and run:

```bash
breeze_pny_prefix="${XDG_DATA_HOME:-$HOME/.local/share}/breeze-tts-pny"
python3 installer/install.py --prefix "$breeze_pny_prefix" --update
```

Host/ports are preserved and the previous configuration is saved as `config.previous.json`. The installer refuses an active installation and verifies the new files before activation. Old versioned assets/application folders remain for inspection; automatic cleanup and a rollback command are not provided. Update the game `.pck` separately and restart the game.

Each run saves `logs/companion-*.jsonl` and its matching `logs/native-*.log`. The JSON log records status, character IDs, adapters and timings, without speech text or audio. Native/game logs can contain local paths, and game logs can contain conversations; review them before sharing. Nothing uploads automatically.

Setup/serving do not edit game settings or saves. Stop the companion before removing its installation folder. Disable or remove the game mod through Settings → Mods and restart; no save migration is required.
