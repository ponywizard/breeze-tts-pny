# Windows installation

This package targets Windows 10/11 x86_64 and Home: Equestria `0.3.0-maredev` with Godot 4.5. You need an AVX2-capable CPU and a working Vulkan GPU driver. Python and the native runtime are included; no compiler, pip or separate Python installation is needed.

Native Windows flatscreen playtesting passed on an RX 6700 XT. Windows PCVR has not been personally playtested and is shipping with that limitation; issues will be investigated case by case. Other GPUs and driver versions have less coverage. [Validation details](VALIDATION.md) are separate from these install steps.

## Install the companion

1. Download `breeze-tts-pny-0.2.1-windows-x86_64.zip` and `breeze-pny-curated-voices-20261107.tar.gz` from the same release. The `.pck` game mod is already included in the ZIP. `WINDOWS-SHA256SUMS` records the expected download hashes.
2. Extract the ZIP to a user-owned folder, such as `C:\BreezePNY`. Place the voice-pack `.tar.gz` **inside that extracted folder**, alongside `setup.cmd`. Leave the voice pack compressed. Keep the folder in its intended location before setup.
3. Run `setup.cmd`. The companion installs in the folder's `companion` subdirectory. Setup copies the voices and adapters, downloads the pinned Q8 model (about 3.6 GB), and verifies the files. Allow at least 6 GB of free space and keep the setup window open until it finishes. Progress and checksum verification are shown in the terminal.
4. Run `start-companion.cmd`. Wait for the `ready` event. Leave this window open while playing; Ctrl+C stops the companion and its owned native process.

If you already have the matching model, open a terminal in the extracted folder and use:

```powershell
.\setup.cmd --model-file "C:\path\to\breeze-tts-2-q8_0.gguf"
```

The file must match the release's pinned SHA-256. A previously verified installed model is reused. Failed downloads leave verified assets intact; downloads restart from the beginning when retried.

## Install and configure the game mod

1. Start the supported game and open **Settings → Mods → Open mods folder**.
2. Copy `game-mod\breeze_tts_pny-0.1.1-windows-x86_64.pck` from the extracted ZIP into that folder. Keep one copy of Breeze TTS PNY and remove previous development PCM/playback/optimization packs. Restart the game.
3. Select the MOSS-compatible TTS provider, enable TTS and automatic voices, and set its URL to `http://127.0.0.1:18792/tts`.
4. Start the companion before loading a world, then check a conversation. Configure in flatscreen first if that is easier before using PCVR.

The MOSS label is the game's existing HTTP provider setting; speech is generated by Breeze.

Your existing saves, LLM and optional STT settings remain in the game's normal profile. The companion supplies TTS only. It does not include or configure an LLM, speech recognition or SSH forwarding.

## Check a voice without the game

With the companion running, open a second terminal in the extracted folder:

```powershell
.\check-voice.cmd --character pinkie_pie --output pinkie-test.wav
.\check-voice.cmd --character spike --output spike-test.wav
```

Listen to the WAV files. The first command should report adapter `pinkie`, and the second `base`. These checks work without an LLM or STT service.

To browse references or replace a character's voice, stop the companion and run `voice-library.cmd`. The [voice library](VOICE_LIBRARY.md) handles audio conversion, previews, saving, and undo in a local browser.

## Optional isolated playtest

Use this only when you want a disposable profile instead of your normal game saves. Extract a fresh supported Windows game release, then run:

```powershell
.\prepare-playtest.cmd "C:\path\to\fresh\game"
```

The helper checks the game version and verifies that its user-data directory is `home-equestria-breeze-windows-playtest` before installing the mod or changing TTS settings. It creates `override.cfg` and `play-breeze-flat.cmd` in that game folder. It refuses to replace an unrelated `override.cfg`.

You can also double-click `prepare-playtest.cmd` and paste the separate game folder's path when prompted. Repeating preparation backs up previous Breeze packs outside the active mods directory and keeps one bundled candidate active. It records the selected folder for the smoke kit's log collector.

Start the companion, then run `play-breeze-flat.cmd` from the prepared game folder. This profile needs its own LLM and optional STT configuration. Keep `override.cfg` in place for that folder to continue using the separate profile. A fresh game folder by itself does not isolate saves.

## Troubleshooting

- **Setup closes with an error:** read the terminal message and retry after addressing it. For this first release, use a simple folder path; shell metacharacters and some Unicode batch paths have not been qualified.
- **The companion cannot start:** run `companion\bin\breeze-pny.cmd doctor` from the extracted folder. Check the installed GPU driver, Vulkan availability and the terminal error. The startup log is in `companion\logs`.
- **Port already in use:** the public TTS port is 18792 and the private native port is 18797. Stop an old companion instance or choose unused ports in `companion\config.json`; use the same public port in the game's TTS URL. The companion does not stop other programs to claim a port. A recently closed native port can take up to 75 seconds to become available.
- **Speech remains local or streaming never enables:** enable TTS/automatic voices, confirm the MOSS URL ends in `/tts`, and start the companion before loading the world. Capability checks retry transient startup failures; reload the world if the service became ready after all retries.
- **LLM/STT fails:** check those services separately. They are not provided by the TTS companion.

The companion writes matching `companion-*.jsonl` and `native-*.log` files under `companion\logs`. The JSON log records status, character IDs, adapter choices and timings, without speech text or audio. Native/game diagnostics can contain file paths, and game logs can contain conversations; review them before sharing.

## Updates and removal

Stop the companion before updating. Extract the next ZIP, keep the voice archive available, and run `setup.cmd --prefix "C:\path\to\existing\companion" --update` from the new extracted folder, or replace the package files in the same extracted folder and run `setup.cmd --update`. Setup preserves host/port choices and retains the previous configuration and older versioned assets.

The game `.pck` is updated separately: replace the prior `.pck` and restart. To remove it, disable it in Settings → Mods or remove that file, then restart. No save migration is needed. Stop the companion before deleting its installation folder.
